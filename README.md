# DSA Patterns in C++ 🚀

This repository contains my daily implementations of core Data Structures and Algorithms, strictly written in modern C++. 

My goal is not only to focus on problem-solving, but to master algorithmic patterns and optimize for Time/Space complexity trade-offs.

## 🧠 Methodology: The 90-Minute Daily Block
I approach my algorithmic training with a structured strict 90-minute block daily routine:

1. **Warm-up (15m):** Spaced repetition of a previously solved problem to build reflexes.
2. **The problem (45m):** Approaching a new problem using a strict interview framework:
   - Clarification & Edge Cases
   - Brute Force Analysis
   - Design & Trade-offs (Time & Space Complexity)
   - Implementation (C++)
   - Dry Run Validation
3. **Autopsy & Refactoring (20m):** Reviewing the code, analyzing edge cases, and discussing C++ specific details.
4. **Commit (10m):** Documenting the optimal solution.
